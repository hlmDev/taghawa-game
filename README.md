# ☕ Taqhawi: A Journey into Saudi Coffee Culture 🇸🇦
</div>

Taqhawi is an immersive mobile application that takes users on a fascinating journey into the rich heritage of Saudi coffee. Combining learning with entertainment, the app allows users to explore the traditional coffee-making process using authentic Saudi ingredients. Through interactive challenges, users will prepare and serve coffee to virtual customers, recreating the essence of Saudi coffee culture. 🌟

## 🧠 Design Thinking Process

1. **🔍 Research**: We conducted thorough market research and user behavior analysis to understand the needs and expectations of our target audience.  
2. **📐 Define**: Clear project goals were set to ensure that the experience was both educational and engaging for the users.  
3. **💡 Ideate**: A creative brainstorming session led to the development of innovative features and designs, all focused on enhancing user interaction.  
4. **🎨 Prototype**: Interactive prototypes were created using **Figma** to visualize and test the design with real users, ensuring intuitive navigation.  
5. **🔄 Test**: After refining the prototype, user feedback was gathered to iterate and improve the design, ensuring it met user expectations.

## 🎮 UI Design & Results

The user interface (UI) design focuses on providing an intuitive, clean, and visually appealing experience. Using **Figma**, we crafted wireframes and final designs, ensuring an aesthetically pleasing experience. The UI was optimized for both ease of use and to visually represent the traditional yet modern atmosphere of Saudi coffee culture. The results speak for themselves with increased user engagement and seamless navigation throughout the app. 📱✨

## 🛠️ Tools Used

- **🎨 Procreate**: Used to create the custom illustrations and characters, bringing to life the essence of Saudi coffee culture in a unique, artistic style.  
- **💻 Xcode**: Utilized for the development and programming of the app, ensuring it runs smoothly across all devices.  
- **🖌️ Figma**: Employed for designing the user interface and creating prototypes to ensure a polished, user-friendly experience.
